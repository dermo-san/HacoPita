アップロードCSVが最新スキーマ（例：total_items, suiban, sizes_raw など）でも、アプリ側で alias とデフォルト補完を行い、この 26 列に整形してからモデルへ渡します。欠損列は 0 や空文字で補われるため、旧スキーマの列が無くても推論できます。

出力仕様

  • アップロードしたCSVの列を保持し、末尾に predicted_box_id を追加してダウンロード
  • 必須列（slip_number）が欠落している場合のみ 400 でエラー内容を表示
  • サンプルCSV：sample_input.csv

APIの使い方

  • POST /api/predict に multipart/form-data で file フィールドを送信
  • ?format=json を付けると JSON (slip_number, predicted_box_id) を返却
