必須列（26列）

  • slip_number (integer)
  • shipment_confirmed_date (datetime)
  • subtotal_amount (integer)
  • total_line_count (integer)
  • bonsai (integer)
  • others (integer)
  • plastic_pots_trays (integer)
  • single_flower_vase (integer)
  • decorative_sand (integer)
  • saucers_mats (integer)
  • books (integer)
  • water_basins (integer)
  • bonsai_seeds (integer)
  • bonsai_class_items (integer)
  • bonsai_soil (integer)

  • bonsai_decor (integer)

  • moss_bonsai (integer)
  • chemicals_fertilizers (integer)
  • wire (integer)
  • decorative_stones (integer)
  • specification (integer)
  • dimensions (string)

出力仕様

  • アップロードしたCSVの列を保持し、末尾に predicted_box_id を追加してダウンロード
  • 推論に必要な列が不足している場合は 400 でエラー内容を表示
  • サンプルCSV：sample_input.csv

APIの使い方

  • POST /api/predict に multipart/form-data で file フィールドを送信
  • ?format=json を付けると JSON (slip_number, predicted_box_id) を返却
